# 百工·墨（Mo）产品分析

> 对标 Adobe Photoshop · 2026-10-19 留档

## 要做什么

**核心职能**：以图层为中心的位图编辑与合成，覆盖选区、修饰、调色到导出全流程。

**必备核心能力**：

- 文档管理：打开/新建/导出（JPG、PNG 等）
- 基础工具：选区（矩形/套索/魔棒）、画笔、橡皮、移动、裁剪、文字、形状
- 图层系统：堆叠顺序、不透明度、混合模式、图层蒙版
- 几何变换：缩放/旋转/翻转
- 基础调整：亮度/对比度、色相/饱和度、曲线
- 撤销与历史记录

**可后置高级能力**：智能主体选择、内容识别填充/修复、智能对象与非破坏性滤镜、滤镜库、矢量与排版增强、批处理脚本、GIF 帧动画、AI 生成。

## 页面呈现样式

**主界面四大区域**：顶部菜单栏＋随工具动态变化的选项栏；左侧竖排工具栏（同类工具长按展开）；中央画布区（多文档标签、缩放平移、灰色画布外区域）；右侧停靠面板区（图层、属性、颜色、历史等，可拖拽重组、Tab 键隐藏）。

**关键对话框/模式**：新建/导出、曲线/色阶调整、自由变换、滤镜画廊、"选择并遮住"蒙版工作区。

**交互特点**：快捷键密集（单键切工具、Ctrl+T/Z）；非模态编辑为主；面板停靠与工作区自定义；像素级高倍缩放；状态栏实时显示缩放比与光标坐标。
