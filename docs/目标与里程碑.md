## 开发目标

以图层为中心的位图编辑与合成工具（对标 Photoshop 核心工作流）：
文档管理、选区、绘制与修饰、图层系统（堆叠/混合模式/蒙版）、几何
变换、调色、撤销历史——覆盖从打开到导出的完整闭环。图像格式编解码
**不经冶**（冶管音视频媒体流，图像用 Rust 生态图像库，M0 选型）；
外壳接入坊。

## 里程碑（每条以真实使用场景为准入）

- **M0 骨架**：Tauri 2 + React + 坊接入（alias 联调轨起步）、图像
  库选型评审（decode/encode、色彩管理）并留档、CI 门禁。
  准入：空窗口跑起来 + 选型文档入 docs/。
- **M1 查看与文档**：打开/保存 JPG/PNG、多标签画布、缩放/平移/
  适合窗口、像素信息（吸管取色/坐标/尺寸）。
  准入：完成一次「打开 → 查看（含放大到像素级）→ 另存」的真实往返。
- **M2 图层与选区**：栅格图层栈、图层不透明度与混合模式、
  矩形/椭圆/套索选区（含抗锯齿边缘）。
  准入：多图层合成一张海报底稿并导出 PNG。
- **M3 绘制与历史**：画笔/橡皮/填充/裁剪、撤销重做与历史面板。
  准入：从零画一张图（中途含改错与回退）。
- **M4 调色与文字**：亮度/曲线/色相、调整即图层（非破坏）、文字
  工具基础。准入：产出一张成品宣传图。
- **M5+（后置池，按需触发）**：魔棒/智能选择、蒙版细化、滤镜库、
  批处理、GIF、AI 能力——产品分析「可后置」清单。

## 依赖与集群对齐

- 依赖坊：M0 起接入；墨是坊「第二工具铺开」(坊 M5) 的候选首发。
- 不依赖冶；若未来有动画/GIF 输出的媒体需求再评估。
- 排期建议：墨排在剪/锻/纸之后、与陶并行启动（等坊 M5 反哺批）。

## 原则

- 每个里程碑以真实使用场景为准入条件，不为了齐备而齐备。
- 图像处理选型优先成熟 Rust 生态（如 image 系），不自研解码器；
  性能热点（大图/笔刷延迟）出现时再评估 GPU 路径。
